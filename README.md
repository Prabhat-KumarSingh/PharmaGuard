# PharmaGuard: Pharmacogenomic Risk Prediction System
This is an AI-powered Web Application which is designed to analyzes patient genetic data (VCF files) and drug names to predict personalized pharmacogenomic risks and provide clinically actionable recommendations with LLM-generated explanations.
